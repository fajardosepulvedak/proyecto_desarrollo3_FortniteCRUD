# Proyecto Fortnite2 CRUD
Este proyecto es un programa CRUD para administrar diferentes elementos del videojuego "Fortnite2", elementos como: personajes, armas,
habilidades y clases para los personajes. El programa fue creado con Java y JavaFx, tiene una conexión a una base de datos MySQL y esta configurado
para funcionar mediante localhost.

## Requisitos para el programa
- Java.
- JDK 25.
- mysql-connector-j-9.4.0.jar (Se encuentra en este repositorio).
- Java Fx.
- Servidor web local (Xampp).
- MySQL o MariaDB.
